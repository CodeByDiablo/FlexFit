# 🏋️ FlexFit — CSS Grid Fitness Landing Page

A modern fitness-themed landing page built using **HTML5** and **CSS Grid Layout**.  
This project focuses on advanced grid structuring, responsive card layouts, modern UI styling, and clean component-based design.

## 📐 Grid Layout Used

```css
grid-template-areas:
  "man app fonts strength"
  "man flex flex strength"
  "redefine flex flex phone"
  "train train rope phone";
```

This layout creates a visually balanced modern dashboard-style interface.

---

## 📱 Responsive Design

Responsive adjustments are included using media queries.

```css
@media (max-width: 1200px) {
  .main-title {
    font-size: 2rem;
  }
}
```
